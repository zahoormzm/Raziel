# Golden integration fixture

`golden_synthetic.mp4` is a deterministic, two-minute, fixed-camera-style
engineering fixture generated by `generate_fixture.ps1`. It contains only
synthetic colour fields and geometric markers. It is suitable for timestamp,
coverage, restart, window, export, and UI integration checks.

It is **not** real surveillance footage, a semantic retrieval benchmark, a
held-out evaluation source, or evidence that a person, vehicle, or bag model
works. Semantic and verifier metrics must come from the independently
controlled Member 4 ledger and held-out pools.

The coloured spans exist only to make frame/interval changes inspectable:

- 5–15 s: red moving rectangle;
- 30–36 s: red vertical rectangle plus black square;
- 45–50 s: blue square decoy;
- 60–65 s: low-light interval;
- 85–95 s: three bounded geometric markers.

Regeneration requires the locally staged FFmpeg binary. Record the produced
source hash and FFmpeg revision in the fixture manifest before using it as a
release fixture.
